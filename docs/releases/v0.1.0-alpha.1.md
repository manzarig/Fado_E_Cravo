**Foundation build — for testing that the mod installs and loads. Nothing is playable or audible yet:** the radio block, tuning screen and broadcast scheduler arrive in M3/M4.

### What's inside
- Fabric 1.21.1 project skeleton (Mojang mappings, GeckoLib, datagen, tests, CI)
- Mid-clip audio engine: radio clips can start partway through, so tuning in joins a programme already on air
- Test audio for three fictional stations — Emissora Lusitana (670 kHz), Rádio Tejo (1035 kHz) and Rádio Atlântico (1440 kHz): 27 European Portuguese spoken clips, 8 original placeholder music pieces and radio sound effects, all through a 1940s AM-radio filter

### Requirements
- Minecraft Java Edition **1.21.1**
- Fabric Loader **0.20.1** or newer
- [Fabric API](https://modrinth.com/mod/fabric-api) (tested with 0.116.17+1.21.1)
- [GeckoLib](https://modrinth.com/mod/geckolib) **4.9** or newer (tested with 4.9.3)
- Optional: [Mod Menu](https://modrinth.com/mod/modmenu) to see the mod in the in-game mod list

### How to run it
Step-by-step Modrinth App guide: [docs/MODRINTH.md](https://github.com/manzarig/Fado_E_Cravo/blob/claude/radio-v1/docs/MODRINTH.md)

Verified before release: the jar loads on a production Fabric 1.21.1 server alongside Fabric API 0.116.17 and GeckoLib 4.9.3.
